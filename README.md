# ELP GPT — LUKE

LUKE is a cross-device, voice-first intelligence system. The primary experience is voice: the home screen is a minimal HUD with no visible command center, chat composer, or tool navigation. Profile, memory, signals, skills, briefings, permissions, and system controls are revealed only from the profile panel.

## Current foundation

- Next.js responsive application for desktop, tablet, and phone
- Installable PWA shell
- Full-screen LUKE voice HUD
- Hidden profile/system drawer for advanced tools
- Deepgram realtime voice conversation
- Hermes or Together AI reasoning
- Honcho long-term profile/session memory
- Permission-first behavior for consequential actions
- CI typecheck + production build validation

## Architecture

| Plane | Responsibility | Current implementation |
| --- | --- | --- |
| Experience | Voice-first HUD and private profile/system drawer | Next.js / React |
| Voice | Realtime speech input/output, barge-in, reconnect | Deepgram Browser Agent SDK |
| Reasoning | LUKE reasoning | Hermes OpenAI-compatible endpoint or Together AI |
| Memory | Persistent user understanding | Honcho peer/session representations |
| Actions | External tools with approvals + audit | Next production milestone |

## Local development

```bash
cp .env.example .env.local
npm install
npm run dev
```

Then open `http://localhost:3000`.

## Required environment variables

At least one reasoning provider is required:

```bash
HERMES_BASE_URL=
HERMES_API_KEY=
HERMES_MODEL=

TOGETHER_API_KEY=
TOGETHER_MODEL=meta-llama/Llama-3.3-70B-Instruct-Turbo
```

Recommended services:

```bash
HONCHO_API_KEY=
HONCHO_WORKSPACE_ID=elp-gpt-luke
DEEPGRAM_API_KEY=
```

Never expose these secrets through `NEXT_PUBLIC_*` variables.

## Provider behavior

Reasoning requests use Hermes whenever `HERMES_BASE_URL` is set. Otherwise LUKE uses Together AI. Honcho supplies long-term context when configured. If Honcho is unavailable, inference continues without memory rather than failing the request.

Realtime voice uses Deepgram's browser agent stack with a short-lived token generated by `/api/deepgram-token`. The permanent Deepgram credential remains server-side.

## Interaction model

The visible home surface deliberately contains only the LUKE HUD, voice state, activation state, ELP GPT signature, and profile button. Tap the HUD to start or stop the realtime voice session. Advanced capabilities are hidden in the profile drawer.

## Development policy

Production changes should be developed on feature branches and merged through pull requests after CI succeeds.
