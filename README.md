# ELP GPT — LUCY

LUCY is a cross-device, voice-first personal intelligence assistant. It is designed to learn each user's preferences and context over time, reason through goals, surface proactive suggestions, and eventually execute approved actions through scoped tools.

## Current foundation

- Next.js responsive application for desktop, tablet, and phone
- Installable PWA shell
- Deepgram realtime voice conversation
- Hermes or Together AI text reasoning
- Honcho long-term profile/session memory
- Permission-first behavior for consequential actions
- CI typecheck + production build validation

## Architecture

| Plane | Responsibility | Current implementation |
| --- | --- | --- |
| Experience | Command center, conversation, responsive layout | Next.js / React |
| Voice | Realtime speech input/output, barge-in, reconnect | Deepgram Browser Agent SDK |
| Reasoning | LUCY text/deep reasoning | Hermes OpenAI-compatible endpoint or Together AI |
| Memory | Persistent user understanding | Honcho peer/session representations |
| Actions | External tools with approvals + audit | Planned next milestone |

See `docs/LUCY_ARCHITECTURE.md` for the production capability map and security model.

## Local development

```bash
cp .env.example .env.local
npm install
npm run dev
```

Then open `http://localhost:3000`.

## Required environment variables

At least one text reasoning provider is required:

```bash
# Preferred when present
HERMES_BASE_URL=
HERMES_API_KEY=
HERMES_MODEL=

# Hosted fallback
TOGETHER_API_KEY=
TOGETHER_MODEL=meta-llama/Llama-3.3-70B-Instruct-Turbo
```

Optional but recommended services:

```bash
HONCHO_API_KEY=
HONCHO_WORKSPACE_ID=elp-gpt-lucy
DEEPGRAM_API_KEY=
```

Never expose these secrets through `NEXT_PUBLIC_*` variables.

## Provider behavior

Text requests use Hermes whenever `HERMES_BASE_URL` is set. Otherwise LUCY uses Together AI. Honcho augments text requests with long-term user context when configured. If Honcho is unavailable, model responses continue without memory rather than failing the entire request.

Realtime voice uses Deepgram's browser agent stack with a short-lived token generated by `/api/deepgram-token`. The permanent Deepgram credential remains server-side.

## Production deployment

The application is compatible with Vercel-style Next.js deployments. Configure environment variables in the deployment platform instead of committing `.env.local`.

Before calling LUCY production-complete, implement the production-critical items listed in `docs/LUCY_ARCHITECTURE.md`, especially authentication, server-side identity mapping, shared voice/text memory, the scoped Hermes action gateway, approval ledger, observability, and end-to-end tests.

## Development policy

Production changes should be developed on feature branches and merged through pull requests after CI succeeds.
