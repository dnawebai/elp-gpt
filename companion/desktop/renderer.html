Desktop Companion

Secure local execution for enrolled ELP devices. The companion only receives commands permitted by its server-side principal and device allowlist.

Enroll this device

Create a one-time companion enrollment in ELP Authority Control, then paste it here. The exchanged device credential is stored locally with restricted file permissions.

Enrolled

Revocation in ELP invalidates the stored credential at the server immediately. Removing this local credential does not delete ELP audit history.

Security model

HTTPS-only server and URL actions · context-isolated renderer · no Node.js in the renderer · no shell execution mode · explicit local command allowlists · server-side revocation.
